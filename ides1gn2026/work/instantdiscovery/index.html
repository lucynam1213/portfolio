Overview
A faster path from browse to buy.

Mobile shoppers abandon carts not because they're uninterested — but because checking availability requires too many taps. This project explored a gesture-native interaction model to close that gap.

Role: End-to-end product design · Tools: Figma · Protopie · Maze · iOS HIG · Deliverables: 3 iterations · High-fi prototype · Usability findings

The Problem
Shopping feels like work,
not discovery.

Checking whether a product is available in your size means 5+ taps and 18 seconds lost. The current tap-to-detail model forces commitment too early.

67%
abandon product pages before selecting a variant
5+

Goal & Context
Design for the browser,
not the buyer.

Focus on the discovery moment — when users are still deciding whether a product is worth their attention.

🎯 Design Goal
  • Evaluate size & color without leaving the feed
  • Use gestures familiar from social apps
  • Two gestures from browse to bag
  • Preserve scroll position throughout
👤 User & Context
  • Mobile-first shoppers aged 18–34
  • High TikTok / Instagram usage
  • Compare multiple products before deciding
  • Abandon on size/color check, not price
Concept
Peek. Swipe. Shop.
Never leave the feed.

A three-gesture system that surfaces product info contextually — triggered by intent, dismissed without disruption.

Iteration Process
Three versions.
Each one earned.

Every iteration responded to real usability findings — not assumptions.

Version 1
Tap to Expand
Inline card expansion pushed the feed layout down. Users lost scroll position. 40% accidental trigger rate.
Disrupted flow
Version 2
Overlay + Tabs
Fixed layout disruption, but tabbed navigation added cognitive overhead — users expected to swipe, not tap tabs.
Too much friction
Version 3 — Final
Gesture-Driven
Long-press, swipe, pull-up. Single unified view. Users: "feels like TikTok for shopping." SUS: 84.
