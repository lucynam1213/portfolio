Hankook TV — Web Homepage

02 / 05   The Problem

Korean content,
American habits.

Korean-American viewers split their time between Korean and American streaming platforms. Hankook TV was losing users who couldn't quickly find the Korean content they wanted among a mix of unfamiliar titles.

Content discovery was broken. No editorial curation, no personalization, no visual hierarchy that communicated what was worth watching.

"Users opened the app, saw a wall of thumbnails, and left within 30 seconds."

Mobile — before redesign

03 / 05   Web Experience

Editorial curation
over algorithm.

Redesigned the homepage around curated editorial shelves — trending in Korea, new releases, genre collections — rather than a flat content grid. Each shelf has a strong visual identity.

Hero carousel replaced with a single featured show that changes weekly. Users reported it felt more like a recommendation from a friend than an algorithm.

Web — redesigned content homepage

04 / 05   Multi-Platform

One system,
every screen.

The same design language — type scale, color system, component library — scaled across web, iOS, and Android. Each platform used native patterns while keeping the visual identity consistent.

Mobile-first approach: core user journeys (discover → watch → continue) designed for thumb reach first, then adapted to larger screens.

05 / 05   Outcome

Discovery
that feels human.

Editorial curation replaced algorithmic walls. Users found content faster and stayed longer. The visual system unified three platforms without losing platform-native feel.
