Data Flow — How Information Moves
Step-by-step flow for key actions in the app
Trainer assigns a workout
🏋️ Trainer
Creates Workout + Exercises
→
Sets assigned_to = User
→
Sets scheduled_date
→
System fires Notification to client
→
Client sees workout on Dashboard
Client completes a workout
👤 Client
Taps "Start Workout"
→
Logs sets & reps per Exercise
→
WorkoutLog saved to DB
→
Workout status → completed
→
Trainer sees update in Client Detail
Client logs a meal
👤 Client
Opens Meal Log tab
→
Adds MealEntry (food + macros)
→
MealLog totals recalculated
→
Trainer reads in Data Review
System detects missed workout
⚙️ System
Checks scheduled_date has passed
→
No WorkoutLog found for that Workout
→
Workout status → missed
→
Fires Notification to client
→
Trainer sees red flag in Dashboard
