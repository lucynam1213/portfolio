Live ↗

A page-by-page ebook reading experience built for Korean-language spiritual content, with adjustable text size, AI voice reading, and a mobile-first layout that feels like a real book.

  • Page-by-page reading with smooth transitions
  • Previous / Next navigation + Go to first page
  • Table of contents with clickable chapter navigation
  • Adjustable text size (A– / A+)
  • Korean text content support (Noto Serif KR)
  • Text-to-speech with ElevenLabs AI voice
  • Mobile-friendly, full-screen reading layout

Hover Quick Preview
Live ↗

A Chrome Extension (Manifest V3) that lets shoppers preview product colors and sizes on hover — without clicking into product detail pages. Works across Shopify, Amazon, Etsy, eBay, and more.

  • Hover over product cards to see available variants instantly
  • Works on Shopify, Amazon, Google Shopping, Etsy, eBay, WooCommerce
  • Shadow DOM popup isolation — no style conflicts
  • Smart color swatches + sold-out filtering
  • 5-minute result cache for performance
  • Enable / disable toggle in the extension popup
  • Privacy-first — zero data collected
