ENTITIES Circular Product Life-cycle Visualization

Focus:

Continuous loop of engagement, tracking, and improvement between clients and trainers.

Stages:

  1. Onboard → Sign up, set goals, connect to trainer.
  2. Plan → Trainer assigns workouts & videos.
  3. Train → Client completes sessions, logs sets.
  4. Log → Meals & body metrics recorded.
  5. Review → Trainer analyzes data, sends notes.
  6. Evolve → Goals updated, program adjusted.
ANALYSIS Circular Product Life-cycle Visualization

Leverage Points:

  • Closing the Train → Log → Review loop drives accountability and retention.
  • Trainer notes after Review re-motivate clients and tighten the feedback cycle.
  • Evolve stage allows program scaling — same client, higher goals over time.

Risks / Challenges:

  • If Log stage breaks (client stops recording meals/metrics), trainer loses visibility.
  • Plan → Train friction if workouts feel too hard or irrelevant — dropout risk.
  • Evolve stage requires trainer time investment — scalability concern for large client loads.
ENTITIES Network Visualization

Focus:

Who/what interacts with whom, and where FitBridge fits in the ecosystem.

Actors:

Client, Personal Trainer, System (auto-notifications).

Artifacts:

FitBridge App, Workout Database, Video Library, Body Metrics Store, Meal Log, Notification Engine, Analytics Dashboard.

Channels:

Mobile App, Push Notifications, In-app Messaging, Trainer Dashboard (web).

Policies:

Data Privacy (GDPR), Health Data Protection, Trainer–Client Access Controls.

ANALYSIS Network Visualization

Leverage Points:

  • FitBridge App as central hub — all actors and artifacts pass through it, making it the single point of accountability.
  • Notification Engine closes the loop automatically — trainer doesn't need to manually chase clients.
  • Analytics Dashboard gives trainers data-driven insight, enabling faster, smarter program adjustments.

Risks / Challenges:

  • Single hub dependency — if the app goes down, all connections break simultaneously.
  • Meal Log & Metrics are client-driven — low logging compliance breaks trainer visibility.
  • Notification overload — too many auto-alerts may cause clients to disengage.
  • Privacy policy complexity — health data requires stricter handling than typical apps.
